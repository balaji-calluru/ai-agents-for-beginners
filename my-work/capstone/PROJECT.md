## Scoping guide (delete once the statement above is written)

A good capstone for this course exercises most Tier A lessons without getting huge:

| Capability | Lesson | How it shows up in the project |
|---|---|---|
| Custom tools | 04 | 2+ tools that act on something real (an API, a file, a calculation) |
| Grounding / RAG | 05 | Answers come from a small knowledge base I supply |
| Multi-agent workflow | 08 / 14 | 2-3 specialist agents (e.g. researcher, writer, reviewer) |
| MCP | 11 | At least one tool exposed through an MCP server |
| Human approval | 06 | A gate before any irreversible action |
| Observability + eval | 10 | Traces plus 5-10 test cases with pass/fail |

Keep it small: one user, one workflow, one data source.
